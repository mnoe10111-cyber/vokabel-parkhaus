# Vokabel-Parkhaus

Installierbarer Vokabeltrainer als Progressive Web App (PWA).

## Funktionen
- Lektionen als Parkebenen
- lokale Vokabel-Datenbank im Browser
- Lernmodus in beide Übersetzungsrichtungen
- Fotoimport mit OCR (Tesseract.js)
- Lernstatistik
- Datenexport und -import
- für Android installierbar

Die Anwendung speichert die Vokabeldaten lokal auf dem jeweiligen Gerät.
